## 三、降噪（二级 · 可展开栏目）

**目标列表（用户口述的最终形态）：**

```
降噪 ▼
  广告推荐
  侧边栏/导航
  评论区
  弹窗/横幅
  会员/登录推销
  视频（暂停播放并隐藏）    可能存在风险
```

> 更新：「视频动画（暂停自动播放）」与「屏蔽所有视频」已按明确要求合并为一个开关——
> 同一个 `prefs.noiseOptions.video` 字段同时驱动两个动作，不再是两个独立开关。

| # | 需求 | 状态 | 说明 |
|---|---|---|---|
| 3.1 | 降噪项、按上述顺序展示 | ✅ | `noiseOrder = ['sidebar', 'comments', 'banners', 'video']`（面板可调 4 项）+ `ads`/`marketing`（按默认值生效，不作为开关暴露） |
| 3.2 | 「视频（暂停播放并隐藏）」带**可能存在风险**提示，且默认关闭 | ✅ | `noise-risk-disclaimer` + `DEFAULT_PREFS.noiseOptions.video = false`（部分站点正文本身即视频，全屏蔽会让阅读层空掉） |
| 3.3 | 「视频（暂停播放并隐藏）」同时暂停自动播放 + 摘掉视频容器 | ✅ | 一个开关驱动两个动作：`reader-layer.js` 的 `INS_pauseAutoplayMedia`（暂停**原页面**的 `video/audio` 并暂存 `autoplay` 属性，这是全项目唯一会改动原页面运行状态的地方，但仍不改原页面 DOM 结构）+ `noise-filter.js` 的 `NOISE_GROUPS.video`（从**克隆体**里摘掉视频容器） |
| 3.4 | 动态降噪的**开关去掉**，改成展开/收起的形式 | ✅ | 二级面板里「降噪」是可展开栏目，纯展开/收起，不再带开关；总开关移到一级界面 |
| 3.5 | 展示「已屏蔽 N 个」小字 | 🟡 | 现文案为「本页已隐藏 **N** 个干扰元素」。需确认是否改为手写稿的「已屏蔽 N 个」 |
